# راهنما: کامپیوترِ خودتان برای آزمایش‌های خودکار (self-hosted runner)

## چرا
هر تغییر پیش از رفتن به برنامه باید آزمایش شود. سرورهای رایگانِ گیت‌هاب برای این پروژه فقط حدودِ ۵ کار هم‌زمان می‌دهند و صف ساعت‌ها طول می‌کشد (۳۱ اکتبر: بیش از ۷۰۰ اجرا در صف، حدودِ ۳۰ اجرا در ساعت). یک کامپیوترِ خودتان این انتظار را خیلی کم می‌کند.

## چه کامپیوتری
- لینوکس (Ubuntu 22.04 یا 24.04)، همیشه روشن و وصل به اینترنت.
- دست‌کم ۴ هسته، ۱۶ گیگ رم و ۱۰۰ گیگ دیسکِ خالی. هر چه قوی‌تر، سریع‌تر.
- یک کاربرِ جدا فقط برای همین کار. روی این کامپیوتر رمز، کیف پول یا فایلِ شخصی نگذارید.

## ⚠️ پیش از هر چیز: ایمنی
ریپو عمومی است. پس در گیت‌هاب این تنظیم را بکنید تا کسی از بیرون نتواند روی کامپیوترِ شما کد اجرا کند:
1. ریپوی `shop` ⇐ **Settings** ⇐ **Actions** ⇐ **General**.
2. بخشِ «Fork pull request workflows from outside collaborators» ⇐ **Require approval for all outside collaborators** ⇐ **Save**.

## نصبِ پیش‌نیازها (یک بار، روی همان کامپیوتر)
```bash
sudo apt update && sudo apt install -y git curl unzip docker.io openjdk-17-jdk
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo bash - && sudo apt install -y nodejs
sudo usermod -aG docker $USER    # سپس یک بار خارج و دوباره وارد شوید
```

## وصل کردن به گیت‌هاب
1. ریپوی `shop` ⇐ **Settings** ⇐ **Actions** ⇐ **Runners** ⇐ **New self-hosted runner** ⇐ **Linux** و **x64**.
2. همان دستورهایی را که گیت‌هاب نشان می‌دهد، به ترتیب در ترمینال بزنید (دانلود، باز کردن، `./config.sh …`).
3. سرِ `./config.sh`، وقتی **labels** را پرسید، بنویسید: `shop-fast`. بقیه را با Enter رد کنید.
4. برای اینکه پس از روشن شدنِ دوبارهٔ کامپیوتر هم کار کند:
   ```bash
   sudo ./svc.sh install && sudo ./svc.sh start
   ```
5. در همان صفحهٔ **Runners**، اجراکننده باید سبز و **Idle** باشد.

برای سرعتِ بیشتر، روی کامپیوترِ قوی می‌توانید همین کار را در ۲ یا ۳ پوشهٔ جدا تکرار کنید. هر کدام یک اجراکنندهٔ جدا می‌شود.

## پس از وصل شدن
به Claude بگویید «اجراکننده وصل شد». کارهای سنگینِ لینوکسی (آزمون‌های سرور و هسته) در یک PR به `runs-on: [self-hosted, shop-fast]` می‌روند.
تا اجراکننده وصل نشده این را عوض نکنید، وگرنه کارها برای همیشه منتظر می‌مانند. ساختِ ویندوز و مک روی گیت‌هاب می‌ماند.

## اگر مشکلی پیش آمد
- اجراکننده خاکستری (Offline) است: کامپیوتر خاموش است یا اینترنت ندارد؛ `sudo ./svc.sh status`.
- حذف: `sudo ./svc.sh uninstall` و سپس در صفحهٔ Runners ⇐ Remove.
