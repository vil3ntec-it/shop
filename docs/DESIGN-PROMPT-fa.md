# ۱. بریف و پشته‌ی فنی

اپلیکیشن **نیتیو اندروید** (نه وب، نه WebView) برای مدیریت دکان خرده‌فروشی در افغانستان.
کاربر: دکاندار افغان، گوشی میان‌رده یا ارزان، اغلب آفلاین، زبان فارسی/دری، جهت RTL.

- **Kotlin** + **Jetpack Compose** + **Material 3 Expressive**
- معماری MVVM + Repository، `StateFlow`، `ViewModel`
- **Room** برای دیتای آفلاین + **DataStore** برای تنظیمات
- `Navigation-Compose` · minSdk 24 / targetSdk 35
- کل اپ داخل `CompositionLocalProvider(LocalLayoutDirection provides LayoutDirection.Rtl)`
- فونت **Vazirmatn** در `res/font/` — وزن‌های 400، 500، 700. هیچ فونت دیگری.
- کتابخانه‌ی **Haze** برای افکت شیشه.

**هدف کیفی:** ظاهر در سطح اپ‌های مالی مدرن ۲۰۲۶، نه Material پیش‌فرض. جسارت بصری در هر صفحه فقط در **یک نقطه** خرج می‌شود.

**سه قانونی که هرگز شکسته نمی‌شوند:**
1. در هر صفحه فقط **یک** المان گرادینتی (دکمه‌ی اصلی یا FAB).
2. در هر صفحه فقط **یک** اقدام غالب.
3. رنگ فقط معنا دارد، هرگز تزئین نیست.

# ۲. تم اصلی — شیشه روی نور آرورا

سه لایه: **نور آرورا** در پس‌زمینه → **پنل‌های شیشه‌ای** روی آن → **محتوای بدون پس‌زمینه**. هیچ کارت توپر خاکستری در کار نیست.

## ۲.۱ لایه‌ی آرورا
پس‌زمینه‌ی پایه: شب `#0B0A14` · روز `#F2F0FA`.
سه دایره با blur سنگین در `Box` ریشه‌ی هر صفحه:

| دایره | قطر | موقعیت | رنگ | آلفا شب | آلفا روز |
|---|---|---|---|---|---|
| ۱ | 230dp | بالا-راست، آفست (+60, −70) | بسته به صفحه | 0.50–0.55 | 0.28–0.30 |
| ۲ | 200dp | چپ، آفست (−70, +40) | بسته به صفحه | 0.36–0.42 | 0.22–0.24 |
| ۳ | 200dp | پایین-راست | بسته به صفحه | 0.28–0.35 | 0.18–0.20 |

**غلبه‌ی رنگ بر اساس صفحه** (ساختار ثابت، فقط رنگ‌ها جابه‌جا):
- داشبورد، حساب، اشتراک → بنفش `#7C5CFF` / نعنایی `#00C39A` / صورتی `#FF5FA2`
- قرض‌داران → صورتی `#FF5FA2` غالب / بنفش / نارنجی `#F0A32B`
- دخل و خرج → نعنایی غالب / بنفش / صورتی
- انبار → نارنجی غالب / بنفش / نعنایی

```kotlin
Canvas(Modifier.fillMaxSize().graphicsLayer {
    renderEffect = RenderEffect
        .createBlurEffect(120f, 120f, Shader.TileMode.MIRROR)
        .asComposeRenderEffect()
}) { /* سه drawCircle */ }
```

**حرکت آرورا:** تنها انیمیشن بی‌پایان مجاز در کل اپ. `rememberInfiniteTransition`، جابه‌جایی هر دایره ۲۰dp، چرخه ۱۸ ثانیه، `RepeatMode.Reverse`.

## ۲.۲ لایه‌ی شیشه
- روی `Box` آرورا: `Modifier.hazeSource(state)`
- روی هر پنل: `Modifier.hazeEffect(state, HazeStyle(blurRadius = 18.dp, tint = ...))`

| ویژگی | شب | روز |
|---|---|---|
| tint پنل | سفید آلفا 0.07 | سفید آلفا 0.62–0.66 |
| بوردر | 1dp گرادینتی سفید 0.35 → 0.08 | 1dp سفید 0.90 |
| شعاع | 20dp پنل · 18dp دکمه و ردیف · 16dp فیلد | همان |

```kotlin
Modifier.border(
    1.dp,
    Brush.linearGradient(listOf(Color.White.copy(0.35f), Color.White.copy(0.08f))),
    RoundedCornerShape(20.dp)
)
```
**بوردر روشن هرگز حذف نشود** — بدون آن شیشه فقط یک لکه‌ی تار است.

**شیشه کجا نباشد:** پشت آیتم‌های `LazyColumn` و لیست‌های اسکرول‌شونده. شیشه فقط برای پنل‌های ثابت: کارت‌ها، نوار پایین، BottomSheet.

# ۳. حالت توپر — فالبک اجباری

بازار هدف گوشی ارزان است. اگر `Build.VERSION.SDK_INT < 31` **یا** `activityManager.isLowRamDevice` **یا** کاربر «کاهش شفافیت» را در تنظیمات روشن کرده:

- آرورا → PNG از پیش‌رندرشده (دو نسخه: روز و شب) در `res/drawable-nodpi`، ساکن
- پنل شیشه‌ای → سطح توپر با این توکن‌ها:

| | شب | روز |
|---|---|---|
| پس‌زمینه | `#0A0D14` | `#F6F5F2` |
| کارت | `#141A26` | `#FFFFFF` |
| فیلد / نوار پایین | `#111722` | `#F1F0EC` |
| بوردر | سفید 7٪ | سیاه 9٪ |

بقیه‌ی رنگ‌ها، ابعاد، تایپوگرافی و موشن دقیقاً یکسان می‌مانند. کاربر نباید حس کند نسخه‌ی ناقص گرفته.

# ۶. موشن — Material 3 Expressive

```kotlin
MaterialExpressiveTheme(motionScheme = MotionScheme.expressive()) { ... }
```
موشن فیزیکی است، نه مبتنی بر مدت‌زمان. دو دسته توکن:
- **Spatial** (موقعیت، اندازه، شکل): فنر با overshoot ملایم
- **Effect** (رنگ، شفافیت، تم): میرایی بالا، بدون پرش

| رویداد | مشخصات |
|---|---|
| فشار دکمه | Spatial، `scale 0.97f` + morph شعاع 18→22dp |
| انتخاب پلن / چیپ / کارت | Spatial، `scale 1.03f` + بوردر بنفش |
| تغییر عدد داخل دکمه | `AnimatedContent` + `slideInVertically` — عدد قدیم بالا می‌رود |
| شمارنده‌ی عدد قهرمان | `animateIntAsState` ۷۰۰ms — **فقط وقتی مقدار واقعاً عوض شده** |
| نوار پیشرفت | ۶۰۰ms، فقط بار اول |
| ورود آیتم‌های لیست | پلکانی ۴۰ms، fade + slide 12dp، فقط بار اول |
| باز شدن بخش جمع‌شده | `animateContentSize` فنری + چرخش ۱۸۰° chevron |
| ورود صفحه | fade + slide افقی ۱/۶ عرض (RTL: از چپ) |
| سویچ روز/شب | توکن Effect، ۲۸۰ms روی رنگ‌ها و آلفای آرورا |
| برق روی دکمه | یک بار هنگام ورود، ۹۰۰ms — هرگز حلقه‌ای |
| هپتیک | انتخاب پلن، ثبت تراکنش، ثبت پرداخت |

- overshoot فقط روی دکمه‌ی اصلی و FAB. اعداد و لیست‌ها بدون پرش.
- **موشن برای توضیح است، نه سرگرمی**: بعد از ثبت پرداخت قرض، نوار پیشرفت همان کارت جلوی چشم پر شود.
- هیچ کانفتی، هیچ bounce تبریک.
- `ANIMATOR_DURATION_SCALE == 0` یا حالت کاهش حرکت یا `isLowRamDevice` → همه‌ی انیمیشن‌ها خاموش.

# ۸. فریم‌به‌فریم

## ۸.۱ Splash
- پس‌زمینه‌ی آرورا ساکن. مربع نرم 78dp شعاع 24dp با گرادینت برند، آیکن دکان 38dp سفید، سایه‌ی بنفش.
- «دکان من» 22sp/700 · زیرش 12sp فرعی «مدیریت فروش، انبار و قرض‌داران».
- نوار پیشرفت 120×4dp گرادینتی.
- حداکثر ۱.۲ ثانیه؛ اگر Room زودتر آماده شد، زودتر عبور کند. عبور: fade 320ms.

## ۸.۲ ورود (Login)
- آیکن‌باکس 46dp گرادینتی با قفل · «خوش آمدی» 19sp/700 · توضیح 12sp فرعی.
- دو `LabeledField`: شماره موبایل (کیبورد عددی) و ایمیل.
- `PrimaryButton` «ارسال کد تایید».
- **آدرس سرور اینجا نیست** — فقط داخل تنظیمات (هم برای کد ورود، هم برای بکاپ).
- خطا: زیر همان فیلد، 11sp قرمز، متن مشخص. نه Toast.

## ۸.۳ کد تایید (OTP)
- چهار خانه‌ی 52dp، `direction = LTR`، فاصله 9dp. خانه‌ی فعال: بوردر نعنایی + حلقه‌ی نور.
- کیبورد خودکار باز · پشتیبانی `SmsRetriever`.
- شمارنده‌ی «ارسال دوباره تا ۰۰:۴۷» → بعد از صفر، لینک فعال.
- کد اشتباه: خانه‌ها قرمز + لرزش افقی 6dp، ۲ نوسان، ۱۸۰ms + هپتیک.

## ۸.۴ داشبورد — اولویت‌محور
شبکه‌ی ثابت دکمه‌ها ممنوع. ترتیب:
1. هدر: سلام + نام دکان (راست) · آواتار حرفی گرادینتی (چپ). **حداکثر دو کنترل در هدر.**
2. `HeroSummary` «فروش امروز» + یک جمله‌ی روایت داده که آفلاین از Room حساب می‌شود: «این هفته ۱۲٪ بیشتر از هفتهٔ گذشته فروختی.»
3. **یک اقدام غالب** که با وضعیت واقعی عوض می‌شود:
   - قرض عقب‌افتاده هست → پنل قرمزتینت + «۵ قرض عقب‌افتاده» + دکمه «پیگیری قرض‌ها»
   - جنس رو به ختم هست → نارنجی + «سفارش بده»
   - هیچ‌کدام → «فاکتور جدید»
4. **وضعیت دکان** به‌صورت ردیف‌های فشرده (نه چهار کارت هم‌وزن): مفاد ماه · فروش ماه · ارزش انبار · قرض بیرون · اجناس رو به ختم.
5. معاملات اخیر — هر ردیف با **مانده‌ی بعد از آن** به‌صورت ریزنویس.
6. `GlassBottomBar`.
- Pull-to-refresh بنفش. اقدامات ثانویه داخل BottomSheet دکمه‌ی «+».

## ۸.۵ فاکتور و فروش
- هدر «فاکتور جدید» + چیپ شماره.
- انتخاب مشتری: ردیف با آواتار + chevron → BottomSheet جستجو + «مشتری جدید».
- هر قلم یک `ListRow` با استپر (− عدد +). حذف با swipe + واگرد.
- کادر خط‌چین «افزودن جنس» → BottomSheet جستجو + اسکن بارکد.
- پنل جمع: مجموع · تخفیف (نعنایی، منفی) · خط · **قابل پرداخت 20sp/700**.
- دو دکمه: «ثبت نقده» (تنها گرادینتی) و «ثبت به قرض» (تینت نارنجی).
- بعد از ثبت: چک‌مارک ۶۰۰ms + هپتیک → پیش‌نمایش فاکتور با «چاپ / اشتراک PDF».

## ۸.۶ انبار
- هدر + جستجو + «+».
- دو کارت کوچک: «مجموع اقلام» و «رو به ختم» (تینت قرمز).
- شبکه‌ی ۲ ستونه: بلوک آیکن 56dp با تینت دسته · نام 12sp/500 · قیمت 13sp/700 · `ProgressLine` موجودی · «موجودی: ۳۶».
- کم‌موجودی: بوردر قرمز + «موجودی: ۲ — کم!».
- تپ → BottomSheet: قیمت خرید/فروش، مفاد هر واحد، تاریخچه، ویرایش، حذف.
- چیپ‌های فیلتر: همه · کم‌موجودی · پرفروش · دسته‌ها.

## ۸.۷ قرض‌داران — **لیست، نه شبکه**
- آرورا صورتی‌غالب.
- `HeroSummary` «جمع طلب از مشتریان» + سه آمار: قرض‌دار · وعده گذشته (قرمز) · وصول این ماه (نعنایی).
- نوار جستجو با آیکن میکروفون.
- چیپ‌های مرتب‌سازی افقی: بیشترین قرض · وعده گذشته · قدیمی‌ترین · نام.
- **پنل شیشه‌ای واحد شامل ردیف‌ها** (نه کارت مربعی جدا برای هر نفر):
  - نوار رنگی عمودی 3dp کنار ردیف (قرمز/نارنجی/نعنایی)
  - آواتار حرفی 40dp با تینت همان رنگ
  - نام 14sp/500 + وضعیت 11sp: «۱۲ روز از وعده گذشته» یا «وعده: ۲۵ سنبله»
  - چپ: مبلغ 16sp/700 هم‌رنگ + «از ۹۶۶» ریز
- **حساب‌های صاف در یک ردیف جمع‌شونده**: «حساب‌های صاف (۲) — یوسف، ت». هرگز هم‌وزن بدهکارها نباشند.
- عقب‌افتاده‌ها همیشه بالای لیست.
- **دکمه‌ی ✕ و مداد روی ردیف ممنوع.** حذف = swipe + واگرد؛ ویرایش = داخل صفحه‌ی جزئیات.
- یک دکمه‌ی گرادینتی پایین: «قرض‌دار جدید».

## ۸.۸ جزئیات قرض‌دار
- هدر: نام + یک آیکن «بیشتر» (ویرایش و حذف داخل منو، نه بیرون).
- **یک** پنل قهرمان «باقی مانده» + دو عدد کوچک خنثی زیرش. سه کارت رنگی رقیب ممنوع.
- برچسب‌های روشن: «قرض گرفته» / «پرداخت کرده» / «باقی» — نه «کل برد» و «کل رسید».
- `ProgressLine` نسبت پرداخت‌شده به کل.
- **تایم‌لاین عمودی**: خط نازک + نقطه‌ی رنگی هر رویداد + مبلغ + تاریخ شمسی. آیکن حذف بیرون نباشد؛ swipe + واگرد.
- دو اقدام: `PrimaryButton` «ثبت پرداخت» و `GlassRowAction` «یادآوری در واتساپ».
- تنظیم وعده‌ی بعدی با تقویم شمسی.

## ۸.۹ دخل و خرج
- آرورا نعنایی‌غالب. `HeroSummary` «باقی صندوق» + دخل/خرج ماه.
- نمودار ستون‌های جفتی ۷ روزه (نعنایی/قرمز)، عرض 9dp، شعاع 4dp، تپ = مقدار دقیق.
- زیر نمودار یک جمله‌ی روایت: «بیشترین خرج این ماه: خرید جنس — ۶۴٪.»
- دو دکمه: ثبت دخل (تینت نعنایی) و ثبت خرج (تینت قرمز) → BottomSheet مبلغ/دسته/یادداشت/تاریخ.
- لیست گروه‌بندی‌شده با سرتیتر روز.

## ۸.۱۰ حساب من
- هدر: chevron برگشت + «حساب من» + آیکن تنظیمات. **فقط همین.** لینک «بازگشت» تکراری زیر هدر حذف شود.
- آواتار حرفی 88dp شعاع 30dp با گرادینت + دکمه‌ی دوربین 30dp روی گوشه. نام 19sp/700 + ایمیل 12sp فرعی LTR.
- پنل اشتراک: آیکن تاج نعنایی + «اشتراک VIP فعال» + «۳۶۵ روز مانده · تا ۱۳ سنبله ۱۴۰۶» + لینک «تمدید».
  **ردیف شکسته نمایش داده نشود** — اگر تاریخ ساخت حساب نامعلوم است، آن ردیف کلاً پنهان شود، نه «— معلوم نیست».
- «اطلاعات شخصی»: `LabeledField` نام · ایمیل (قفل، آلفا 0.72 + آیکن قفل) · شماره موبایل.
  یک جمله‌ی خاکستری ریز زیرشان: «ایمیل و شماره پس از ثبت قفل می‌شوند — راه ورود و بازیابی رمز همین‌هاست.» هشدار قرمز/نارنجی ممنوع؛ این خطر نیست، یک واقعیت است.
- «دکان»: نام فروشگاه + ریزنویس «این نام روی سربرگ فاکتور چاپ می‌شود.»
- **`PrimaryButton` فقط یکی: «ذخیره تغییرات».**
- «همگام‌سازی»: `GlassRowAction` با آیکن refresh + «آخرین بار: ۱۴ سنبله ۱۴۰۵ · ۹:۴۰».
- «خروج از حساب»: فقط متن قرمز وسط‌چین + ریزنویس «دفتر دکان روی همین گوشی می‌ماند و پاک نمی‌شود.» + دیالوگ تایید.
- **تنظیمات آدرس سرور فقط در این بخش یا صفحه‌ی تنظیمات** — با دکمه‌ی «آزمایش اتصال» و سه حالت: در حال آزمایش / وصل شد / ناموفق با علت مشخص.

## ۸.۱۱ اشتراک (VIP)
- هدر ساده. هیرو: مربع 64dp شعاع 22dp گرادینتی با تاج + «دکان بدون محدودیت» 22sp/700.
- **فقط تفاوت‌ها**: پنل شیشه‌ای با چهار ردیف چیزی که VIP باز می‌کند. لیست رایگان تکرار نشود؛ یک خط جمع‌شونده: «۷ امکان رایگان هم مثل قبل باقی است».
- سه قرص مدت: عنوان 12sp · قیمت 17sp/700 · «روزی ۱۴ ؋» 10sp. انتخاب‌شده: بوردر بنفش + تینت + scale 1.03.
- خط صرفه‌جویی وسط‌چین 11sp نعنایی که با انتخاب عوض می‌شود.
- **یک** دکمه‌ی گرادینتی که متنش از انتخاب می‌آید: «گرفتن ۶ ماهه — ۲,۵۰۰ ؋».
- ریزنویس: «هماهنگی و پرداخت از راه واتساپ · بدون قرارداد» + ردیف شیشه‌ای واتساپ.
- اگر اشتراک فعال است: پنل وضعیت با تیک نعنایی + روزهای باقی + نوار پیشرفت، بین هدر و هیرو.
- **قواعد:** فقط یک بَج («پیشنهاد ما»)، نه دو بَج رقیب · به‌جای قفل خاکستری بنویس «با VIP باز می‌شود» · نام پلن و روزهای باقی‌مانده باید با هم بخوانند (ماهانه ↔ حداکثر ۳۰ روز).

# ۹. حالت‌های اجباری هر صفحه
- **بارگذاری** → اسکلت شیمری با شکل واقعی محتوا. هیچ اسپینر گردان.
- **خالی** → یک جمله‌ی دعوت‌کننده + یک دکمه. نه «چیزی اینجا نیست».
- **خطا** → چه شد + چطور درست می‌شود، در یک جمله + «تلاش دوباره».
- **آفلاین** → نوار باریک بالای صفحه. اپ باید کاملاً بدون اینترنت کار کند.
- **در حال انجام** → نوار پیشرفت با زمان تخمینی: «در حال ارسال کد… معمولاً ۱۰ ثانیه».
- **پیش‌نویس** → اگر وسط ساخت فاکتور اپ بسته شد، برگردد.

# ۱۰. دسترسی‌پذیری
شیشه‌ی روی نور دشمن خوانایی است:
- کنتراست متن روی پنل در **بدترین حالت** (روشن‌ترین نقطه‌ی آرورا زیرش) ≥ 4.5:1. اگر نشد، آلفای tint بالا برود، نه رنگ متن.
- گزینه‌ی «کاهش شفافیت» در تنظیمات → حالت توپر بخش ۳.
- حالت کنتراست بالا با نسبت ≥ 7:1.
- TalkBack: هر کارت آمار یک `contentDescription` روایتی («فروش امروز، دوازده هزار و چهارصد و پنجاه افغانی، هجده درصد بیشتر از دیروز»).
- بزرگ‌نمایی فونت تا ۲۰۰٪ بدون شکستن layout.
- همه‌ی لیست‌ها `LazyColumn` با `key` پایدار · هیچ کار سنگینی روی Main thread.
- **مبالغ با `Long`** (به واحد کوچک) — هرگز `Float`/`Double`.

# ۱۱. ممنوعیت‌ها
- شبکه‌ی کارت مربعی برای لیست افراد
- کارت با رنگ پرشده‌ی کامل به‌جای نوار لهجه‌ای
- دکمه‌ی حذف یا ویرایش همیشه‌درمعرض روی ردیف‌های لیست
- بیش از یک دکمه‌ی گرادینتی در یک صفحه
- بیش از دو کنترل در هدر، یا تکرار هدر پرکنترل در همه‌ی صفحات
- نمایش ردیف شکسته («—»، «معلوم نیست») به‌جای پنهان کردنش
- ارقام لاتین، تاریخ با اسلش، متن انگلیسی در UI فارسی
- شیشه روی شیشه · بیش از سه دایره‌ی آرورا · blur زنده روی گوشی کم‌رم
- طلایی در کنار این پالت · هدر گرادینت آبی
- گرادینت روی متن یا آیکن ریز · سایه‌ی خاکستری Material پیش‌فرض
- Toast برای خطای فیلد فرم · آیکن filled و outline مخلوط
- انیمیشن ورود روی هر بخش · هر انیمیشن بی‌پایان جز آرورا
