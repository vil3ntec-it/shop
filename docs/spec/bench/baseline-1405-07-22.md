## یافته‌ها (بی اصلاح در این PR — فقط ثبت)

1. **وب دادهٔ مرجع را نگه نمی‌دارد.** دفترِ ۲۰ هزار کالایی ۹ میلیون نویسه است و Chromium آن را با `QuotaExceededError` رد می‌کند؛ ردیف‌ها فقط تا بسته شدنِ صفحه در حافظه می‌مانند. این همان F0-23 است (هشدار در ۷۰٪) و انتقال به IndexedDB در فاز ۱.
2. **قاعدهٔ فعلیِ RULES («هر صفحه زیر ۱۰۰ms با ۱۰۰۰ کالا») همین حالا شکسته است**، حتی روی این ماشینِ تند: محصولات ۳۲۴ و انبار ۳۶۴ میلی‌ثانیه. با CPU ×۴ نزدیکِ ۲ ثانیه‌اند (بودجهٔ کامپیوتر ۳۰۰ms).
3. **با ۲۰ هزار کالا** محصولات ۱۳ و انبار ۱۶ ثانیه طول می‌کشند (فهرستِ بی‌مجازی‌سازی). صفحه‌هایی که ربطی به کالا ندارند (تنظیمات، بیشتر) هم از ~۳۵ به ~۳۶۰ms رسیده‌اند ⇒ کاری که با تعدادِ کالا بزرگ می‌شود در هر `goTo` تکرار می‌شود (ریشه بررسی نشده).
4. **اسکن تا ردیف با ۲۰ هزار کالا ۶۰۶ms است** (بودجه ۱۰۰ms). جست‌وجوی بارکد O(1) است (`barcodeIndex`)، پس هزینه در کشیدنِ دوبارهٔ چیزی پس از افزودن به سبد است — حدس: `renderCart` → `renderQuickSelectGrid` (تأیید نشده).
5. بالا آمدنِ وب با ۱۰۰۰ کالا روی CPU ×۴ حدودِ ۲ ثانیه است.

## اجرا روی سخت‌افزارِ مرجع (صاحبِ محصول)

همه از ریشهٔ ریپو. هیچ‌کدام دادهٔ دکان را نمی‌خوانند یا نمی‌فرستند؛ فقط عدد چاپ می‌کنند. خروجی را در PR بگذارید.

**وب روی کامپیوترِ مرجع (ویندوز ۱۰، Celeron/i3، HDD):** Node 20+ را نصب کنید، بعد
```
npm i -g playwright@1.56.1
node bench/web.mjs --channel msedge --json web-ref-pc.json
```
(`--channel msedge` همان Edge ِ خودِ ویندوز را به کار می‌برد؛ دانلودِ Chromium لازم نیست.)

**شروعِ سردِ کامپیوتر:** ویندوز را ریستارت کنید، بعد
```
powershell -ExecutionPolicy Bypass -File bench\desktop-cold-start.ps1 -Runs 10
```
«دورِ نخست» را جدا گزارش کنید — شروعِ واقعاً سرد روی HDD همان است. زمان تا ساخته‌شدنِ پنجرهٔ پاسخ‌گوست (کفِ شروع).

**شروعِ سردِ اندروید (گوشیِ ضعیف و متوسطِ ۹.۱):** USB debugging روشن، گوشی وصل، بعد
```
bash bench/android-cold-start.sh 10
```
عددِ `TotalTime` ِ خودِ اندروید (تا نخستین فریم) را p50/p95 می‌کند. گوشی را پیش از اجرا یک بار ریستارت کنید.

**وب روی گوشی:** خودکار نیست. اندروید: Chrome ِ گوشی با `chrome://inspect` به کامپیوتر وصل و برگهٔ Performance؛ آیفون: Safari ِ مک ← Develop. این بخش در ابزار نیامده است.

**حجم‌ها و شمارِ آزمون‌ها:** `node bench/sizes.mjs` و `node bench/tests.mjs --run-server`.
