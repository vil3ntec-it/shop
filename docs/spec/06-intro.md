## ۶. فهرست کامل قابلیت‌ها

**راهنما**

اولویت‌ها:
- **P0** = پایه. بدون آن محصول قابل اتکا نیست.
- **P1** = برای رسیدن به سطح رقبا.
- **P2** = برای جلو زدن از رقبا.

وضعیت اولیه (از بررسی کد؛ ایجنت باید تأیید کند):
- **موجود** = حفظ و فقط کامل شود.
- **ناقص** = بخشی هست.
- **ندارد** = باید ساخته شود.
- **بررسی** = معلوم نیست؛ اول بررسی شود.

فاز هر قابلیت در انتهای همان خط یا بلوک چندخطی آمده است (قواعد فاز در بخش ۸). هر شناسه دقیقاً یک فاز دارد. هر قابلیت به سناریوهای بخش ۷ وصل است.
