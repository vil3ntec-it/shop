## ۱۷. چک‌لیست انتشار عمومی

انتشار عمومی تنها وقتی مجاز است که همهٔ موارد مرتبط زیر شواهد داشته باشند:

- [ ] تمام F0های بحرانی و مهم یا اصلاح و آزموده شده‌اند یا ریسک و راهکار موقت با تأیید صاحب محصول ثبت شده است.
- [ ] هیچ آزمون موجود حذف/غیرفعال یا ضعیف نشده است؛ آزمون‌های اجباری CI واقعاً اجرا شده‌اند.
- [ ] build از شاخه/tag مجاز، با artifact امضاشده و hash قابل‌تأیید ساخته شده است.
- [ ] پشتیبان رمزدار ساخته و restore واقعی روی محیط جدا موفق شده است.
- [ ] migration و rollback روی کپی داده اجرا و تطبیق مالی/موجودی سبز شده است.
- [ ] تست tenant isolation و جدایی دکان/پمپ سبز است.
- [ ] آزمون‌های مالی idempotency، هم‌زمانی، retry، crash و قطع برق سبز است.
- [ ] کانال beta، health check، توقف انتشار و rollback ثابت شده است.
- [ ] سیاست اشتراک/آفلاین و تصمیم‌های وابسته قبل از فاز مربوط بسته شده‌اند.
- [ ] برای فاز فروش آنلاین، سفارش ناموجود، جایگزینی، لغو/برگشت، وزن نهایی، COD و تسویه پیک آزموده شده‌اند.
- [ ] پایش خطا، صف sync، فضای دیسک، آخرین backup و تأخیر سفارش فعال است.
- [ ] متن حریم خصوصی با رفتار واقعی کد هماهنگ است و رضایت موقعیت/داده اختیاری درست عمل می‌کند.
- [ ] گزارش نشست و وضعیت هر شناسه در `STATUS.md` به‌روز است؛ موارد ناقص صریحاً باقی می‌مانند.
