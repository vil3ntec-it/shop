# باز کردن در اندروید استودیو

## نکته‌ی اول
اندروید استودیو **فایل APK را باز نمی‌کند** — پوشه‌ی پروژه را باز می‌کند.
APK خروجی است، نه ورودی.

## راه اول (پیشنهاد من): مستقیم از گیت‌هاب

در اندروید استودیو:
`File → New → Project from Version Control`
و این آدرس را بده:

```
https://github.com/vil3ntec-it/shop.git
```

بعد از کلون، **پوشه‌ی `android` را به عنوان پروژه باز کن** (نه ریشه‌ی مخزن):
`File → Open → .../shop/android`

مزیتش: هر بار که تغییری می‌دهم، با `git pull` می‌گیری. لازم نیست فایل جدید بفرستم.

## راه دوم: فایل zip

فایل `tohid-android.zip` را باز کن و در استودیو:
`File → Open → پوشه‌ی tohid-android`

## اولین بار چه اتفاقی می‌افتد

۱. استودیو می‌گوید «Gradle sync». بگذار انجام شود — حدود ۵ تا ۱۵ دقیقه طول می‌کشد
   چون همه‌ی کتابخانه‌ها را دانلود می‌کند. اینترنت لازم است.
۲. اگر گفت SDK نصب نیست، دکمه‌ی پیشنهادی خودش را بزن تا نصب کند.

## چیزهایی که باید باشد

| مورد | مقدار |
|---|---|
| JDK | ۱۷ (استودیو معمولاً خودش دارد) |
| Android SDK | API 35 |
| حداقل نسخه اندروید گوشی | ۷ (API 24) |

اگر استودیو JDK دیگری داشت:
`Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK → 17`

## ساخت APK

از داخل استودیو: `Build → Build Bundle(s)/APK(s) → Build APK(s)`

یا از خط فرمان داخل پوشه‌ی `android`:
```bash
./gradlew assembleDebug
```
خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## ولی برای آپدیت لازم نیست استودیو باز کنی

نسخه‌ی جدید را با یک تگ منتشر کن:
```bash
git tag v1.0.1
git push origin v1.0.1
```
گیت‌هاب خودش APK می‌سازد و در Releases می‌گذارد. گوشی‌ها از
**تنظیمات → به‌روزرسانی برنامه** آن را می‌گیرند و نصب می‌کنند.

## اگر خطا دیدی

متن کامل خطا را بفرست. چند خطای رایج:

- **«SDK location not found»** → استودیو خودش دکمه‌ی نصب می‌دهد؛ بزن.
- **«Unsupported Java»** → Gradle JDK را روی ۱۷ بگذار (بالا توضیح داده شد).
- **دانلود وابستگی‌ها گیر می‌کند** → اینترنت یا فیلترشکن را چک کن؛
  Gradle به `dl.google.com` و `repo.maven.apache.org` نیاز دارد.
