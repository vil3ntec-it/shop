# shop

برنامه‌ی مدیریت فروشگاه — برنامه‌ی اندروید، آیفون و کامپیوتر، سرور، و فروشگاهِ آنلاین (ویترین و بازارچه) روی وب.
نسخه‌ی وبِ مدیریتِ فروشگاه به تصمیمِ صاحب برداشته شد (۱۴۰۵/۰۸/۲۰؛ `docs/RULES-fa.md`، بخشِ نخست).

- **ادامهٔ کار بی ما (برنامه‌نویس یا هوشِ مصنوعی):** [`docs/MAINTAINER-fa.md`](docs/MAINTAINER-fa.md)
- **کارهایی که فقط صاحب‌کار می‌تواند:** [`docs/OWNER-TODO-fa.md`](docs/OWNER-TODO-fa.md)
- **پرسش‌های بزرگ (ظرفیت، امنیت، داده، آیفون…) با شاهد:** [`docs/QA-BIG-QUESTIONS-fa.md`](docs/QA-BIG-QUESTIONS-fa.md)

```
برنامه اندروید ──┐
برنامه کامپیوتر ─┼─→  REST API  →  Node.js  →  PostgreSQL
برنامه آیفون ────┘        └─→  ویترین و بازارچه (server/public)
```

| پوشه | چیست |
|---|---|
| `index.html`، `sw.js` | صفحه‌ی «برنامه را نصب کنید» روی GitHub Pages (جای وبِ دکانِ برداشته‌شده؛ پشتیبانِ دفترِ مانده در مرورگر) و سرویس‌ورکرِ خداحافظی |
| `license/` | هسته‌های مشترکِ JS (هم‌زادِ کاتلین با بردارهای `test-vectors/`، کلاینت‌های مرجعِ همگام‌سازی برای آزمونِ سرور) — هیچ صفحه‌ای آن‌ها را بار نمی‌کند |
| `android-native/` | برنامه‌ی بومی اندروید (Kotlin + Compose) |

## در یک نگاه

- هر کاربر حساب خودش را دارد؛ ورود با شماره و کد پیامکی، حساب گوگل، یا رمز.
- هر دکان یک شناسه دارد و صاحب دکان با «کد شاگرد» شاگردهایش را روی همان
  دکان می‌آورد. اشتراک به دکان وصل است، نه به یک نفر.
- اطلاعات اصلی روی سرور می‌ماند؛ گوشی یک نسخه‌ی محلی برای کار در نبود
  اینترنت دارد و به محض وصل شدن، تفاوت‌ها همگام می‌شوند.
- پشتیبان‌گیری خودکار روی سرور، با امکان بازگرداندن روی هر سرور دیگر.
