توحید — نصابِ همهٔ کامپیوترها
================================

این بسته برای ویندوز، مک و لینوکس است. فقط فایلِ سیستمِ خودتان را باز کنید:

  ویندوز ۱۰ و ۱۱ (۶۴ بیت)  ⇐  «Install-Windows.bat» را دوبار کلیک کنید
  مک (اپل M1 تا M4 یا اینتل) ⇐  «Install-Mac.command» را باز کنید — نوعِ تراشه خودش تشخیص داده می‌شود
  لینوکس (دبیان، اوبونتو، مینت) ⇐  «Install-Linux.sh» را اجرا کنید (رمزِ کاربر را می‌پرسد)

یا مستقیم از پوشه‌ها:
  Windows/Tohid-Windows-Setup.exe
  Mac-Apple-Silicon/Tohid-Mac-AppleSilicon.dmg
  Mac-Intel/Tohid-Mac-Intel.dmg
  Linux/Tohid-Linux.deb

نکته‌ها
-------
• ویندوز: اگر پنجرهٔ آبیِ «Windows protected your PC» آمد ⇐ More info ⇐ Run anyway.
• مک: اگر گفت «باز نمی‌شود چون از توسعه‌دهندهٔ ناشناس است» ⇐ روی فایل کلیکِ راست ⇐ Open.
• برنامه فقط ۶۴ بیتی است. اگر ویندوزِ ۳۲ بیتی دارید: تنظیمات ⇐ System ⇐ About ⇐ System type؛
  اگر نوشته «x64-based processor»، ویندوزِ ۶۴ بیتی نصب کنید. روی کامپیوترِ واقعاً ۳۲ بیتی
  نسخهٔ مرورگری کار می‌کند: https://vil3ntec-it.github.io/shop/
