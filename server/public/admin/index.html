ورودِ دومرحله‌ای (اختیاری)

این کلید را در برنامهٔ تأیید (Google Authenticator، Microsoft Authenticator، Aegis، 2FAS…) دستی وارد کنید، یا روی همان گوشی این پیوند را بزنید. بعد کدِ شش‌رقمی را بنویسید.

این ده کدِ بازیابی فقط همین یک بار نشان داده می‌شوند. جایی امن (بیرون از این کامپیوتر) بنویسید؛ هر کدام یک بار به‌جای کدِ گوشی کار می‌کند.
